# AUTO_API_SCREENPLAY

Proyecto de automatización de API con Serenity BDD, Serenity Rest y patrón Screenplay para validar el flujo CRUD del servicio de eventos.

## Repositorios relacionados

- Backend: https://github.com/Jomruizgo/ticketing_project_week1
- Frontend: https://github.com/emolinaf99/FrontendTicketing

## Ejecución

Desde la raíz del proyecto:

- `./gradlew test aggregate`

## Reporte

El reporte Serenity se genera en:

- `target/site/serenity/index.html`
